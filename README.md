## Sobre o projeto

O **Você Importa** é uma aplicação web desenvolvida como atividade acadêmica de conscientização sobre o Setembro Amarelo.

O projeto busca oferecer um espaço digital acolhedor, com informações sobre saúde emocional, mensagens de apoio e orientações para pessoas que estejam passando por momentos difíceis.

A aplicação não substitui o acompanhamento de profissionais de saúde. Seu objetivo é incentivar o diálogo, o acolhimento e a busca por ajuda especializada.

---

## Objetivo

Desenvolver uma página responsiva utilizando HTML, CSS e JavaScript, aplicando conhecimentos de estruturação, estilização e interatividade.

Além dos aspectos técnicos, o projeto procura reforçar a importância do cuidado com a saúde mental e mostrar que pedir ajuda é uma atitude de coragem.

---

## Funcionalidades

A aplicação apresenta os seguintes recursos:

* Botão para ligar gratuitamente ao CVV pelo número 188;
* Link de acesso ao site oficial do CVV;
* Exercício interativo de respiração guiada;
* Gerador de mensagens acolhedoras;
* Informações sobre CAPS e unidades de saúde;
* Orientações para procurar uma rede de confiança;
* Layout adaptado para celulares e computadores;
* Recursos de acessibilidade e navegação;
* Aviso informando que o projeto não substitui atendimento profissional.

---

## Tecnologias utilizadas

O projeto foi desenvolvido com:

* **HTML5:** responsável pela estrutura e pelo conteúdo da página;
* **CSS3:** utilizado na aparência, nas animações e na responsividade;
* **JavaScript:** responsável pelas mensagens aleatórias e pelo exercício de respiração.

## Estrutura do projeto

```text
setembro-amarelo/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### Descrição dos arquivos

* `index.html`: contém a estrutura e os textos apresentados na página;
* `style.css`: define as cores, fontes, animações e adaptação para diferentes telas;
* `script.js`: controla as funcionalidades interativas;
* `README.md`: apresenta as informações e a documentação do projeto.

---

## Como executar

1. Baixe ou clone este repositório;
2. Abra a pasta do projeto no Visual Studio Code;
3. Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server;
4. Verifique se os arquivos `index.html`, `style.css` e `script.js` estão na mesma pasta.
